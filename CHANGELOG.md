# Changelog

Файл скрипта: `eclipse.lua` (до v52 включительно назывался `eclipse vNN.lua`). Версия — `RAP.VERSION` в файле и тег в GitHub Releases.

## v52 — 2.0 beta

Исправления по аудиту v51 (`AUDIT_v51.md`). Формат данных совместим: в базе только новые необязательные поля.

### Исправлено
- **Смена карты.**
  - `curtime` на новой карте начинается заново. Старые таймеры держали включёнными:
    - Auto OS — DT был выключен;
    - Break LC;
    - голос «enemy on-shot» — стратегия «Prefer body» не действовала и не училась;
    - индикатор DEFENSIVE.
  - Теперь эти таймеры сбрасываются в `level`, и каждая проверка «до момента X» ограничена своей длительностью.
  - Незавершённые записи о выстрелах врагов тоже очищаются при смене карты.
- **Журнал решений.**
  - Раньше исходы выстрелов в журнал не поступали, а откат не был подключён.
  - Теперь смены стратегии и профиля AA проверяются. При вердикте «хуже» смена откатывается, и вариант блокируется на `verify.block_s` секунд.
  - Только записывать вердикты, без отката: `/eclipse cfg verify.rollback 0`.
- **Strategy AI.** Затухание старого опыта больше не применяется повторно при каждой загрузке скрипта (новое поле `dts`).
- **AA AI.** При сохранении статистики по врагам остаются самые свежие враги, а не случайные (новое поле `ets` в `rap2_ai`).
- **База.**
  - Отказ по размеру больше не «залипает» после успешной записи.
  - При отказе появляется уведомление.
  - Selftest предупреждает при 75 % лимита.
  - `ST.corr` больше не растёт без ограничения.
  - Счётчики стратегий округляются до 3 знаков.
- **Dormant aimbot.**
  - Детерминированные точки (грудь / живот / таз, с учётом приседа) вместо случайной высоты.
  - Свежесть записи считается по собственной метке времени; слайдер timeout работает на всём диапазоне.
  - Выборка разброса делается один раз за скан.
- **Надёжность.**
  - `U.safe` для сырых событий: `player_blind`, `grenade_prediction`, `console_input`.
  - Из текста для `console_exec` удаляются управляющие символы.
  - `/eclipse selftest release` снимает и Delay Shot.
  - `/eclipse db` знает `decisions` и `deaths`.

### Производительность
- AI Peek не собирает позиции врагов, когда функция выключена.
- Константы вместо таблиц-литералов в AA-движке.

### Прочее
- 0 предупреждений luacheck.
- Добавлен `.luacheckrc`.
- Новый параметр `CFG.dormant.hit_radius` (по умолчанию 16, как раньше).
